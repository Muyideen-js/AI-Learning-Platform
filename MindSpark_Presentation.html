MindSpark

AI-Powered Learning Companions

Hackathon Submission 2026

The Problem

Traditional online learning platforms suffer from:

  • One-size-fits-all content with no personalization
  • Lack of real-time interaction and feedback
  • No voice-based learning experiences
  • Static curricula that don't adapt to learners

Our Solution

MindSpark transforms education through AI-powered study companions that:

  • Teach through natural voice conversation
  • Generate personalized 8-module curricula with AI
  • Track progress and adapt to individual learning pace
  • Make learning feel like talking to a knowledgeable friend

Key Features

🗣️

Voice-Interactive Learning

Speak to your AI tutor and receive spoken responses using Web Speech API

📚

AI-Generated Curricula

Complete 8-module courses with quizzes created instantly by Gemini AI

📊

Smart Progress Tracking

Cumulative stats across sessions unlock new modules automatically

System Architecture

User Flow

1. Create Companion → Choose topic, voice, teaching style
2. AI Generates Curriculum → 8 modules with quizzes in seconds
3. Start Session → Voice or text input with real-time transcription
4. AI Responds → Natural language teaching with TTS
5. Progress Tracked → Time & messages counted cumulatively
6. Module Unlocked → Celebration modal when requirements met

Data Model

Companions: Store AI tutor configuration and curriculum
Sessions: Track conversation history and timestamps
moduleProgress: Cumulative time, messages, completion status
